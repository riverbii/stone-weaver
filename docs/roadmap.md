# stone-weaver 路线图（2026-08-17 制定）

> 目标来源：`project_stone_weaver.md`「初建」段。本文档把最终目标倒推为可验收的阶段，并记录关键决策。改动路线图时同步更新本文档。

## 0. 最终目标

**agentic 叙事引擎**——用 LLM + 知识图谱**重建/续写《红楼梦》**：

- 人物当对象、情节当有向图（人物对象 = 世界状态，情节 = 状态转移）
- 基于癸酉本情节弧或自定义故事弧
- 里程碑产物：**"癸酉情节版红楼梦"** —— 公版前80回（锁世界模型+文风）＋癸酉本情节补后28回（引擎重建）
- 交付：Web 阅读器（现有门户页承接）＋可选 PDF

**本质三层能力**：
1. **世界模型**（静态知识图谱）：人物/关系/地点/事件
2. **文风引擎**（前80回锁定风格）：生成文本像曹雪芹
3. **叙事引擎**（动态推演）：世界状态 + 情节弧 → 生成下一步 → 更新状态 → 一致性校验

3. **图谱原料**：公版前80回（`gongban_rb`）优先——无版权争议、文风纯正。后28回从 `guihui_v3` 全文提取情节弧（**不再需要补调研**，`docs/guihui_plot.md` 的缺口自动消解）。

## 3. 路线图（每阶段可验收）

### 阶段 0｜收尾（半天）
- [x] LLM 链路打通：llm.py 加载 `data/.env`，key 验证通过（opencode Zen 网关，deepseek-v4-flash）
- [x] 世界模型提取单回试点（第1回）——结论见下
- [ ] 程甲本：后台慢抓或放弃，不阻塞主线

**试点结论（2026-08-17，第1回 gongban_rb）**：
- ✅ 提取质量好：甄士隐/贾雨村/空空道人/茫茫大士/渺渺真人/女娲氏等全中，别名/氏族/归属字段完整
- ⚠️ **网关对长文本不稳定**：6000 字符以上偶发 63s 空响应 / 500 错误；≤3000 字符稳定
- ⚠️ 规则兜底（rule_based_mentions）噪音大（"何如/何地方"误判人名），仅可作辅助信号
- 🔧 提取策略：**按 ~2000-3000 字分段 + 指数退避重试**；每回约 4-5 段、2-3 分钟，80 回全量约 3-4 小时（后台批量可接受）
- 🐛 已修 bug：`world/extract.py` 的 `EXTRACT_PROMPT.format()` 被 JSON 花括号破坏 → 改用 `.replace()`

### 阶段 1｜世界模型构建（核心第一步，1-2 周）
- 原料：公版前80回 `gongban_rb`
- 用 `stone_weaver/world/extract.py` 跑通 LLM 批量提取：
  - **人物** `characters`：标准名/别名（宝玉=宝二爷=绛洞花主）/性别/氏族/归属/首次出场回
  - **关系** `relationships`：父子/夫妻/主仆/姐妹… 带出处回目
  - **地点** `locations`：大观园/荣国府内部建筑
  - **事件** `events`：每回事件序列（人物×地点×动作）—— **情节有向图的节点**
- 验收：四表有数据；图谱浏览/统计页（"谁在第几回见了谁"）；人物同名归并准确率抽查
- 关键点：**80→81 衔接的世界状态**（谁活着/谁在哪）在阶段1就为后28回建立快照

### 阶段 2｜文风锁定 + 叙事引擎原型（1-2 周）
- 文风：前80回原文 few-shot 风格参考（prompt 级约束 + 输出评估），先验证"生成一段像不像"
- 引擎最小闭环：**情节弧 → LLM 生成 → 世界模型校验（人物是否活着/在场/性格一致）→ 更新事件图**
- 验收：单回"生成 + 校验"窄闭环跑通，人工判定文风合格率

### 阶段 3｜后28回重建（1-2 周）
- 从 `guihui_v3` 81-108 提取逐回情节弧（已有全文，无需再调研）
- 驱动引擎逐回生成，人工把关一致性
- 验收：81-108 回引擎重建版全部产出，与情节弧对齐、人物一致性通过校验

### 阶段 4｜整合呈现（收尾）
- "癸酉情节版"成书：前80回公版原文＋后28回引擎重建
- 接入门户首页"自家版本"卡片（从占位变实装）
- 可选 PDF 导出

## 4. 风险与注意

- **版权**：癸酉本全文仅本地/受控展示（线上已去"吴氏石头记增删试评本"名号）；图谱提取以公版为主原料。
- **一致性**：叙事引擎最大风险是人物死亡/不在场还出场——校验器必须绑定世界状态快照。
- **文风**：癸酉本原文文风与公版有差异，后28回生成以公版文风为基准、癸酉本为情节骨架。
- **成本**：80回全量提取需批量调用 LLM，试点后估算 token 成本再全量。
